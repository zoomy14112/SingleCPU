ROM 大小不小于 2048 bytes
RAM 大小不小于 1024 bytes
中断处理程序地址：0x1c

读入 switch 的地址为 0xf0000000
读入键盘按键的地址为 0xf4000000
输出数码管的地址为 0xe0000000
输出声音频率信息的地址为 0xe4000000
单位：100MHz 分频下的周期数，即10ns（如：输出数据为 382210 时即代表 3.8221 ms，对应的频率约为 261.63 Hz）
输出声音音量信息的地址为 0xe5000000
单位：为 0~16 的 17 个档位（如输出数据为 0 则为静音，输出数据为 16 则为最高音量）
输出 LED 的地址为 0xec000000

控制声音输出的模块见此目录下 audio.v（可能）
